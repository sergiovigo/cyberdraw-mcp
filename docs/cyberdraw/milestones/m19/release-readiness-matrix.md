# M19 Release Readiness Matrix

Status: READY FOR REVIEW.

This matrix separates current technical capability from release readiness. A
working demo is not the same as an externally distributable MVP.

Severity:

- BLOCKER: must be resolved before external distributable MVP.
- REQUIRED: must be resolved before final MVP closure or product acceptance.
- RECOMMENDED: should be addressed before public beta.
- DEFERRED: explicitly outside MVP or future Architecture Intelligence work.

## Readiness Scoring Method

M19 avoids a single arbitrary percentage. It evaluates six dimensions:

| Dimension          | Current decision               | Reason                                                                                |
| ------------------ | ------------------------------ | ------------------------------------------------------------------------------------- |
| Product capability | Strong internal/demo readiness | Creation and read-only analysis work in local real environments.                      |
| Operability        | Medium                         | First-run, restart, troubleshooting and clean-machine acceptance need consolidation.  |
| Security           | Medium/high for local profile  | Local loopback/trusted-client model is clear; external exposure remains out of scope. |
| Distribution       | Low                            | Packaging, license inventory and asset provenance are not ready.                      |
| Documentation      | Medium                         | Tool docs are strong; product-level MVP docs are new in M19 and need review.          |
| Acceptance         | Medium/low                     | Many technical tests exist, but final product acceptance is not executed.             |

## Blocker Summary

External distributable MVP is blocked by:

1. clean/reproducible installation;
2. deterministic editor startup and asset behavior;
3. complete licenses/notices;
4. draw.io asset provenance/pinning;
5. release versioning policy;
6. accepted packaging strategy;
7. clean real product acceptance.

Internal MVP is not blocked, but it carries limitations until M20/M21 close.
